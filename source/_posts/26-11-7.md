## 音高跟随评估的best practice

> 在YingMusic-SVC上进行

1. 固定实验数据

   - 使用NUS-48E数据集，ADIZ、JLEE作为目标，其余十位作为源歌手
   - 每位源歌手四条录音，共40个源片段；目标各取一段音频，组成80个转换配对
   - 保存配对清单：配对ID、源文件、目标参考文件
2. 提取并保存源F0

   - 使用RMVPE对全部源片段提取F0，统一输入采样率和提取参数
3. 固定推理设置

   - 固定checkpoint、配置、步数、CFG、精度和种子，启用自动移调
4. 提取输出F0
5. 计算指标并验证评分器

   - Acc@50：源参考有声帧中，输出有声且误差小于50 cent的比例
   - F0 MAE：双方有声帧上的平均绝对音分误差
   - 浊音覆盖率：源参考有声帧中，输出仍有声的比例
   - 清浊误报率：源参考无声帧中，输出出现F0的比例

## Python异常分类

- AttributeError：
  - 当我们尝试访问对象不存在的属性时，会触发AttributeError

  ```python
  try:
      x = 10
      print(x.length)
  except AttributeError as e:
      print("AttributeError:", e)
  ```
- FileNotFoundError：
  - 在文件操作中，当尝试打开不存在的文件时，会引发FileNotFoundError

  ```python
  try:
      with open("nonexistent_file.txt", "r") as file:
          content = file.read()
      except FileNotFoundError as e:
          print("FileNotFoundError:", e)
  ```
- KeyError：
  - 在字典操作中，访问不存在的键会引发KeyError

  ```python
  try:
      my_dict = {"name": "Alice", "age": 25}
      print(my_dict["gender"])
  except KeyError as e:
      print("KeyError:", e)
  ```
- NameError：
  - 当尝试使用未定义的变量或函数是，会引发NameError

  ```python
  try:
      myfunction()
  except NameError as e:
      print("NameError:", e)
  ```
- TypeError：
  - 当尝试使用未定义的变量或函数时，会引发TypeError

  ```python
  try:
      result = "5" + 10
      except TypeError as e:
          print("TypeError:", e)
  ```
- ValueError：
  - 在数据类型正确但值不符合预期时，会引发ValueError

  ```python
  try:
      number = int("abc")
  except ValueError as e:
      print("ValueError:", e)
  ```
